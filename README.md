# 家族ボード（Family Board）

家族5人（父・母・長男・次男・長女）の予定を **人ごとの縦レーン** で並べ、
大きな時計と月カレンダーを添えて常時表示するボードです。

古いiPhone → HDMIアダプタ → モバイルモニター にミラーリングして使います。

```
   Googleカレンダー（予定の入れ物）
        │
        ├─→ TimeTree（外部カレンダー表示。家族はスマホで今まで通り見られる）
        │
        └─→ Google Apps Script（gas/Code.gs がJSONで配信）
                 └─→ このPWA（古いiPhoneのSafariで全画面表示）
```

## なぜTimeTreeから直接引っ張らないのか

TimeTreeの外部連携API（Connect App）は **2023年12月22日に終了** しました。
またTimeTreeの外部カレンダー連携は「取り込む」一方通行で、
TimeTreeの予定を書き出す機能はありません。

そのため **Googleカレンダーを予定の入れ物にして、TimeTreeはそれを表示するだけ** に
役割を変えるのが、いちばん壊れにくい構成です。

---

## STEP 1｜Googleカレンダーを用意する

運用方法は2通り。どちらでも動きます（併用も可）。

### 方式A：1つのカレンダーに全員分を入れる（おすすめ・移行がラク）

いま使っている「ファミリー カレンダー」をそのまま使い、
予定のタイトルの **先頭に担当の目印** を付けます。

```
【父】出勤
【長男】サッカー練習
母: 歯医者
#長女 保育園
```

対応する書き方は `【父】` `[父]` `父:` `父：` `#父 ` の5通り。
表示するときは目印が自動で取り除かれます。

目印を付けなかった予定は「みんな」レーンに入ります（家族全員の予定はこれでOK）。

> 目印の代わりに **Googleカレンダーの予定の色** で振り分けることもできます。
> `gas/Code.gs` の `colorIds` に色番号を入れてください。

### 方式B：5人分のカレンダーを作る

Googleカレンダー（PC版）の左メニュー「他のカレンダー」＋ →「新しいカレンダーを作成」で
父・母・長男・次男・長女の5つを作り、家族と共有します。
作ったカレンダーIDを `gas/Code.gs` の `calendars` に入れます。

> **すでに目印が入っている予定がある場合**
> 習い事などの予定が `【2年生】PM-練習 - ○○FC` のように、
> 最初から `【 】` 付きで入っていることがあります。
> その場合は `Code.gs` の該当するメンバーの `tags` に `'2年生'` のような既存の目印を足すだけで、
> タイトルを一切書き換えずにそのレーンへ自動で振り分けられます。

## STEP 2｜Google Apps Script を設置する

1. https://script.google.com/ を開き「新しいプロジェクト」
2. `gas/Code.gs` の中身を **全部** 貼り付ける
3. 冒頭の `CONFIG` を家族用に書き換える
4. 関数の選択欄で **`listMyCalendars`** を選んで ▶ 実行
   → 初回はアクセス許可を求められるので承認
   → 「実行ログ」にカレンダーIDが出るので、必要なIDを `CONFIG` に貼る
5. **`testOutput`** を ▶ 実行して、ログにJSONが出れば成功
6. 右上「デプロイ」→「新しいデプロイ」→ 種類「**ウェブアプリ**」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
7. 発行された `.../exec` で終わるURLをコピー

> 「全員」でもURLを知らない人には届きません。**このURLは家族以外に共有しないこと。**
> 心配ならCONFIGの `accessKey` に合言葉を設定し、URLの末尾に `?key=合言葉` を付けます。

## STEP 3｜画面を公開する

このフォルダをGitHub Pagesなどに置いて、iPhoneから開けるURLにします。

公開先: https://yasuokun-pro.github.io/family-board/

更新するときは、`sw.js` の `VER` を上げてから push します。

```bash
git add -A && git commit -m "更新内容" && git push
```

**取得URL（GASのURL）はソースには書きません。**
iPhone側で ⚙ から入力すると、その端末のブラウザにだけ保存されます。
なので公開リポジトリでも家族の予定が漏れません。

---

## STEP 4｜古いiPhoneをボード端末にする

1. Safariでボードを開き、共有ボタン →「**ホーム画面に追加**」
2. 追加されたアイコンから起動（全画面になる）
3. 画面右上の **⚙** をタップ → STEP 2 のURLを貼る →「保存して再読込」
4. iPhone本体の設定：
   - 設定 → 画面表示と明るさ → **自動ロック → なし**
   - 設定 → 画面表示と明るさ → 明るさを下げる（焼き付き＆発熱対策）
   - **画面の向きをロック**（横向きで固定）
   - 設定 → アクセシビリティ → アクセスガイド → ON
     （起動後にサイドボタン3回押しで、他のアプリに移れないよう固定できる）
5. **電源に挿しっぱなし** にする
6. HDMI変換アダプタでモバイルモニターへ。iPhoneを **横向き** にすると
   モニターいっぱいに表示されます

> 有機ELのiPhone（X / XS / 11 Pro）は焼き付きに注意。
> ⚙ の「焼き付き防止」をONにしておくと、3分ごとに画面を数ピクセルずらします。

---

## STEP 5｜TimeTree側の設定（家族のスマホ）

Googleカレンダーの予定をTimeTreeにも出しておくと、移行の違和感がありません。

1. iPhone本体の 設定 → カレンダー → アカウント → アカウントを追加 → Google
   （家族ボード用のGoogleアカウントを追加し、カレンダーをON）
2. TimeTreeアプリ → 左下メニュー → 設定 → **外部カレンダー**
   → 追加したカレンダーにチェックを入れる

これでTimeTreeの画面にもGoogleカレンダーの予定が並びます。
**予定の入力はGoogleカレンダー側で** 行ってください（TimeTreeに入れたものはボードに出ません）。

## 天気について

時計の下に、気温・天気マーク・最高最低気温・降水確率を出します。
データは [Open-Meteo](https://open-meteo.com/)（APIキー不要・無料）です。

**地域の設定** — ⚙ の「天気を表示する地域」に市区町村名を入れて保存します。
`市` `区` まで入れると一つに絞れます。同名の場所が複数あるときは候補が出るので選んでください。

> 日本には同じ地名が多く、たとえば「横浜」だけで検索すると
> 青森県や福岡県の横浜が先に出ます。必ず候補の県名を確認してから選んでください。

地点の座標は**リポジトリには入らず、その端末の中だけ**に保存されます。

## メンバーの色を変える

`app.js` の先頭にある `MEMBERS` の `color` を書き換えます。

```js
var MEMBERS = [
  { key: 'father',   label: '父',   color: '#8FA0B5' },  /* グレー */
  { key: 'mother',   label: '母',   color: '#FF7AA8' },  /* ピンク */
  { key: 'son1',     label: '長男', color: '#4FA3FF' },  /* 青 */
  { key: 'son2',     label: '次男', color: '#4ED9A4' },  /* 緑 */
  { key: 'daughter', label: '長女', color: '#FFD84D' }   /* 黄 */
];
var SHARED = { key: 'shared', label: 'みんな', color: '#B98BFF' };  /* 紫 */
```

離れた場所から見るボードなので、隣り合う色は離れた色相にするのがおすすめです
（オレンジと黄、青とシアンなどは遠目で見分けにくくなります）。

## 使い方

| 操作 | できること |
|---|---|
| 左右にスワイプ / `‹` `›` | 前後の日に移動（5分放置で自動的に今日へ戻る） |
| `今日` | 今日に戻って再読込 |
| `⚙` | 取得URL・天気の地域・表示時間帯・更新間隔・メンバー名の変更 |

- 予定は5分ごとに自動更新（間隔は⚙で変更可）、天気は20分ごと
- 前後の日に移動すると、天気もその日の予報に変わります（8日先まで）
- 進行中の予定は枠が光ります／終わった予定は薄くなります
- 日付が変わると自動で今日の画面に切り替わります
- 通信が切れても、最後に取れた内容を表示し続けます

## 困ったとき

**「取得できません」と出る**
- GASのデプロイが「アクセスできるユーザー：全員」になっているか確認
- URLが `/exec` で終わっているか（`/dev` は不可）
- GASエディタで `testOutput` を実行してエラーが出ていないか確認

**予定が「みんな」にばかり入る**
- タイトルの目印が先頭にあるか確認（`【父】` は全角カッコ）
- `Code.gs` の `tags` に、実際に使っている呼び方を足す

**時刻がずれる**
- Googleカレンダーの設定でカレンダーのタイムゾーンを「東京」にする
  （「ファミリー カレンダー」は現在 UTC になっています）

**画面を更新したのに変わらない**
- `sw.js` の `VER` を上げてから再アップロードする
